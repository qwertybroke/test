# VESPER Explorer — переработанная модель (v2)

Исследовательский корабль по фото-референсу «VESPER Explorer». Модель целиком процедурная: Python + Blender `bpy`
(без ручного моделирования), поэтому любую размерность, раскладку отсеков или окна можно поменять в
`vesper/layout.py` и пересобрать за несколько секунд.

Габариты: **≈ 103 × 36,8 × 26,8 м** (с гондолами и антеннами), корпус 22 × 18,8 м. Метры, масштаб 1:1.
В Blender нос смотрит в −Y, верх +Z; в glTF/Unity нос в +Z, верх +Y.

## 2. Описание фото-референса

- **Силуэт.** Длинный (≈ 5:1) гранёный «утюг»: плоская верхняя палуба, вертикальный верхний борт, ниже пояса
  борт заваливается внутрь несколькими гранями к узкому тёмному килю. Нос — тупой тёмный гранёный щит.
- **Окраска.** Двухцветная: светло-серая/почти белая матовая краска сверху и на борту, графитовая (почти чёрная,
  слегка металлическая) — киль, ниши, торцы, силовые шпангоуты. Лёгкая потёртость, потёки, без глянца.
- **Обшивка.** Крупные панели разной длины, разделённые тонкими швами-канавками; рёбра граней сняты фасками;
  встречаются лючки, сервисные лючки, мелкая маркировка. Панели — часть оболочки, не накладки.
- **Окна.** Тёмные утопленные ниши с подсвеченным изнутри интерьером: верхний ряд (крупные группы окон),
  средний пояс — длинная тёмная ниша с окнами и белыми световыми полосами под ней.
- **Мостик.** Панорамное тонированное остекление с тёмными импостами — по бортам носовой части и лобовое,
  уходящее к носовому щиту; над ним сплошная светлая крыша и надстройка со световой полосой («козырёк»).
- **Нос.** Тёмный щит с вертикальными белыми световыми полосами по углам и горизонтальными снизу.
- **Верх.** Продольный хребет-надстройка с тёмной полосой окон, блоки оборудования, решётки, сенсоры,
  три группы антенн (сдвоенная в корме, высокая одиночная, кластер у носа).
- **Гондолы.** Две длинные гранёные гондолы у кормы по бортам на коротких пилонах: светлый верх, тёмный низ,
  тёмный передний обтекатель с голубым светящимся кольцом, щелевые огни.
- **Надписи.** «VESPER» тонким разреженным гротеском, ниже «EXPLORER» с линиями, эмблема-шеврон слева
  и светлый шеврон на тёмном шпангоуте справа.

## 3. Что сделано в v2

### Обшивка — одна цельная оболочка
- Корпус — **один связный меш** (наружная + внутренняя поверхность, толщина 0,6 м), построенный лофтом
  профиля по ~500 шпангоутам. Никаких плит поверх.
- **Фаски**: каждое ребро профиля (киль, грани днища, борт/скулы, палуба, хребет) снято фаской 7 см.
- **Швы**: V-канавки 8 × 3,5 см прорезаны в самой сетке (средняя линия тройки утоплена) — продольные
  по поясам и поперечные со смещением по каждому поясу, как раскладка панелей на референсе.
- **Ниши**: утопленный пояс окон (35 см) и ниша верхнего ряда (30 см) с фасками на торцах — тоже часть оболочки.
- **Окна** — настоящие проёмы: откос от наружной обшивки до внутренней, тёмная рама, стекло на глубине 16 см.
- Текстуры корпуса перегенерированы **без запечённых панелей** (краска, потёки, микроцарапины) — рисунок
  панелей даёт только геометрия.

### Экстерьер по референсу
Гранёный нос (шпангоуты = импосты остекления), тёмный носовой щит со световыми полосами, панорамное
остекление мостика со сплошной крышей, хребет с окнами обзорного салона и световым «козырьком»,
две гондолы с цельной гранёной оболочкой и швами, голубыми кольцами воздухозаборников и соплами,
пилоны, 5 маршевых сопел, антенны, сенсорные купола, радиаторные решётки, РСУ, навигационные огни,
логотип VESPER / EXPLORER, бортовой номер VX-984, маркировка.

### Интерьер — уютный и многофункциональный
| Палуба | Отсеки |
|---|---|
| **S** (хребет, 7,4 м) | Обзорный салон 52 × 11 м: диванные группы у панорамных окон, бар, телескоп, библиотечный уголок |
| **A** (жилая, 3,2 м) | Мостик с капитанским уровнем и пилотской «ямой», 8 кают по 4 × 8 м с окнами, каюта капитана, конференц-зал, кают-компания с камбузом и островом, библиотека-лаунж с «камином», медотсек, спортзал, душевые, прачечная, оранжерея, мастерская, кладовая |
| **B / C** (−1,6 / −6,0 м) | Носовой салон, шлюз со скафандрами и шлюзовой камерой, стволы с винтовыми лестницами и лифтом |
| **B+C** (двусвет) | **Производственный цех 1** — 26 × 17 м, высота 8,6 м; **Производственный цех 2** — 21 × 17 м; между ними техузел (подстанция, склад материалов) с воротами 7 × 3,9 м и **пост управления цехами** с обзорными окнами; реакторный отсек и машинное отделение (двусвет) |

Цеха спроектированы под линии, которые строят игроки: свободный пол с сеткой 1 м / 4 м и анкерными
точками каждые 2 м, разметка рабочих зон 7,2 × 7,2 м, **точки подключения** (силовая / вода / данные) вдоль обоих
бортов, мостовой кран на подкрановых путях, галереи по бортам на уровне палубы B с окнами, высокопролётный
свет, ворота между цехами.

Итого: 38 отсеков, 42 раздвижные двери (`Door_*` со створками `*_Leaf_L` / `*_Leaf_R`, свойства
`type = sliding_door`, `openDistance`, `slideAxis`, `room`), 99 точечных источников, ≈ 333 тыс. треугольников.

## 4. Файлы (`export/`)

| Файл | Для чего |
|---|---|
| `Vesper_Explorer.glb` | Основной файл: геометрия, PBR-материалы (ORM, normal, emission), свет, extras дверей |
| `Vesper_Explorer.fbx` + `Textures/` | FBX для Unity без плагинов, текстуры по относительным путям |
| `Vesper_Explorer.blend` | Сцена Blender 5.0, коллекции `Exterior`, `Interior`, `Doors`, `Lights` |
| `Vesper_Explorer_Colliders.glb/.fbx` | `COL_Hull`, `COL_Interior_Structure`, `COL_Interior_Furniture` |
| `Unity/` | Импортёр (материалы Standard/URP, коллайдеры, двери), `VesperSlidingDoor.cs`, `Vesper_Materials.json` |
| `Previews/` | Контрольные рендеры Cycles: экстерьер, интерьеры, поэтажные планы |

Unity: как и раньше — GLB через `com.unity.cloud.gltfast` или FBX + папка `Unity/` (импортёр сам настроит
материалы, двери и коллайдеры). Скрипт двери теперь находит створки по суффиксу `Leaf_L` / `Leaf_R`.

## 5. Пересборка

```bash
uv run --with numpy --with pillow python ship/gen_textures.py              # текстуры → ship/build/Textures
uv run --python 3.11 --with bpy --with numpy python ship/build.py          # → ship/export/*
uv run --python 3.11 --with bpy --with numpy python ship/render.py ship/export/Vesper_Explorer.blend ship/export/Previews
python3 ship/check_glb.py ship/export/Vesper_Explorer.glb                  # проверка GLB
```

| Модуль | Что внутри |
|---|---|
| `vesper/layout.py` | Размеры корпуса, шпангоуты носа, палубы, отсеки, окна, швы, световые полосы |
| `vesper/hull.py` | Профиль, лофт, фаски, V-канавки, ниши, проёмы с откосами, остекление, нос и корма |
| `vesper/exterior.py` | Гондолы, пилоны, двигатели, хребет, антенны, огни, декали |
| `vesper/interior.py` | Перекрытия по контуру обшивки, переборки с проёмами, двери, свет, наполнение отсеков |
| `vesper/props.py` | Мебель и оборудование |
| `vesper/materials.py` | Таблица материалов, сборка шейдеров, таблица для Unity |
